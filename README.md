# Yash Saini – Data‑Driven Multiverse

This repository contains the source code for my upgraded portfolio hosted on GitHub Pages.  It demonstrates modern frontend techniques and data‑driven storytelling.

## Features

* Cosmic star‑field background with adaptive themes.
* Sticky navigation with animated wormhole scrolling.
* Site‑wide search (Lunr.js) and voice commands (Web Speech API).
* Personalised project recommendations using TensorFlow.js.
* Interactive demos: churn prediction, data‑health scanner (with Web Workers) and gamified ETL pipeline builder.
* Progressive Web App: offline support via service worker and installable manifest.
* Accessibility and performance optimisations (lazy loading, Intersection Observer, ARIA labels).

## Development

Copy the files into your GitHub Pages repository.  Ensure that `manifest.json` and `sw.js` are at the project root, and place icons in the `assets/icons/` folder.

For local development, run a static server (e.g., `python3 -m http.server`) and visit `http://localhost:8000`.  To deploy, push to your `main` branch if using GitHub Pages.
